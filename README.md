# TP_GESTION_DES_VOLS_BILLETS_DAVION


...En analysant le projet de la gestion des vols, ma conception sur le projet est la suivante :
- D’abord le projet a pour objectif de faciliter l'achat de billets d'avion sans que les passagers ne se déplace à l'agence pour l’achat ou d'annuler leur réservation. 
- Ensuite, ce projet permettra aussi à l'agence de mieux gérer les réservations et aussi l'information personnelle des passagers. Les réservations annulées et autres.
- Et enfin, cela permettra à l'agence de gagner du temps pour la gestion et la configuration des places disponibles et occupées. Toute en sachant les passagers qui occupe les places disponibles et aussi les passagers qui ont annulé leur réservation.
